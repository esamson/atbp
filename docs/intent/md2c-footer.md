# Intent: md2c generated-page footer

Confirmed statement of intent (output of an interview-me session). This captures
*what* we want and *why*, not the implementation. The spec is downstream.

## Outcome

Every md2c-generated Confluence page includes a footer that identifies its
Markdown source and directs readers there to make edits.

## User

Readers and contributors of Confluence pages generated by md2c.

## Why

Readers should know that the page was generated from Markdown, where to edit
the source, and what changed recently.

## Success

The footer contains:

- The warning: "Do not edit here. This page was generated from markdown source."
- A `git clone` command using the remote of the local checkout.
- The source Markdown file's repository-relative path.
- The five most recent Git commits affecting that file, each showing date,
  author, abbreviated commit hash, and commit message.

## Constraint

Source location and history refer to the Markdown file used to generate the
page, and the clone command uses the local checkout's remote.

## Out of scope

- Preventing edits in Confluence.
- Displaying the file's full Git history.
